Compose helps writers find inspiration and beat writers block by generating words based on any idea they describe. 
Live Link: https://dynamic-prompt-generator-iota.vercel.app/

It starts with just a input box and generate button. The user types any length prompt and the program generates word chips that appear like a cloud above, received from Gemini. These words can be saved by clicking, and will appear in a box below for later use. Once the user is satisfied with the amount of words, they can begin composing sentences with the words they saved. It also includes a "common words" section that contains words like he, she, they, etc., to create complete sentence. The goal of this application is to give writers a place to create without pressure.

Tech Stack: React, Node/Express, Gemini, Render/Vercel for hosting.
